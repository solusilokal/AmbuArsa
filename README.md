# AmbuArsa - Wisata Kolam Pemancingan

Landing page interaktif untuk wisata kolam pemancingan keluarga dan galatama AmbuArsa.

## Fitur Utama
- **Hero & Profil**: Informasi lengkap, alamat, dan tombol reservasi.
- **Katalog Layanan**: Kolam Galatama, Kolam Kiloan, dan Sewa Peralatan.
- **Daftar Harga**: Transparan dan terjangkau untuk tiket dan sewa.
- **Galeri Momen**: Preview foto interaktif dengan lightbox viewer.
- **Tanya Jawab (FAQ)**: Accordion interaktif untuk informasi pengunjung.
- **Kata Angler (Testimoni)**: Ulasan dari para angler.
- **Form Reservasi WhatsApp**: Formulir pemesanan langsung terhubung ke WhatsApp Admin.
- **Fitur Bagikan (Share Modal)**: Bagikan tautan ke WhatsApp, Twitter/X, Facebook, atau Salin Tautan.

---

## Cara Menjalankan & Preview

### Cara 1: Standalone HTML (Langsung Buka Tanpa Node.js)
Cukup buka file `preview.html` langsung di browser favorit Anda (Google Chrome, Microsoft Edge, Mozilla Firefox, dll).

### Cara 2: Menggunakan File Batch (1-Click)
Klik dua kali file `start-dev.bat`. Skrip ini otomatis:
1. Mendeteksi Node.js.
2. Menginstal dependensi jika belum ada.
3. Menjalankan dev server di `http://localhost:3000` dan membukanya di browser.
4. Jika Node.js tidak tersedia, skrip otomatis membuka `preview.html`.

### Cara 3: Melalui Terminal (Vite Dev Server)
```bash
# 1. Install dependensi
npm install

# 2. Jalankan server lokal
npm run dev

# 3. Build untuk produksi
npm run build
```
